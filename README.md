# Maps

> Full Stack Web Development Bootcamp — Sprint 15, Day 3

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)

## About

Covers the Map interface and its implementations in Java, focusing on key-value pair storage and retrieval. This assignment demonstrates HashMap, TreeMap, and common mapping patterns.

## Key Concepts

- `Map` interface and key-value associations
- `HashMap` and `TreeMap` implementations
- Iterating over entries, keys, and values
- Handling collisions and duplicate keys
